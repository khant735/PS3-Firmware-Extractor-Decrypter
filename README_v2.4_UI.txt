PS3 SPKG Extractor GUI v2.4

UI change: Extraction log, File results, and Key audit notebook tabs use bold Segoe UI 11pt labels and larger 20px horizontal / 11px vertical padding.

All v2.3 functionality is retained, including key tracing and the missing-private-key ERROR filter.

CORE_OS package unpack: uses unpkg -s and cosunpkg for the CORE_OS_PACKAGE format.
SPKG external extractor: invokes the configured external backend for compatible SPKG files; support is backend dependent.

Run START_WINDOWS.bat from the v2.4 folder.
