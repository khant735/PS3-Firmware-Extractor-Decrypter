v3.0: New Batch firmware decrypt + full extract mode. Extracts recognised TAR payloads inside firmware .pkg files, uses cosunpkg.exe for recognised CORE_OS tables when installed, and preserves all decrypted plaintext. Unsupported formats are reported separately. Outputs firmware_inner_package_report.json/.csv. Does not parse proprietary BDPT/BDIT formats. The Windows toolchain and full real-firmware run have not been tested in this environment.
